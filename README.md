# HealthCare-Data-Analysis
Healthcare Analytics Dashboard

This project involved designing a comprehensive, multi-page Power BI dashboard to analyze a large healthcare dataset containing over 55,000 patient records and 17 columns. 
To effectively address more than 20 specific client questions without creating visual clutter, the dashboard was strategically organized into four distinct pages.
Key Focus Areas

General Overview — High-level summary of the dataset and overall trends
Patient Demographics — Detailed insights into patient profiles and characteristics
Hospital and Doctors — Analysis of institutional performance and care delivery
Insurance and Billing — Financial aspects, policy coverage, and claims data

Conclusion
By structuring the dashboard into focused, intuitive sections, complex healthcare data was transformed into a clear and navigable experience. 
This approach enabled non-technical stakeholders to easily explore insights, improving understanding and supporting better decision-making across patient care, 
hospital operations, and financial management.
